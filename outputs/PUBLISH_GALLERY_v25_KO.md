# 제목

Extended Pickup Icons Range v2.5 — 순정 아이콘 표시 거리 조정

# 본문

샘플과 장비를 찾기 쉽게 하면서 게임 분위기를 유지하도록, 순정 플로팅 아이콘의 표시 거리만 조정합니다. 빛기둥이나 발광 텍스처는 사용하지 않습니다.

Arsenal에서 세 기능을 각각 켜고 끌 수 있습니다.

- **Samples:** 일반·희귀·슈퍼·포장형 샘플의 내부 `ViewDistance`를 35로 설정
- **Supplies:** 탄약상자, 수류탄팩, 자극제, 재보급품의 내부 값을 20으로 설정. 자극제는 기존 핑 아이콘을 자동 표시
- **Equipment & Mission Items:** 지원무기·백팩·샘플 운반체 등은 35, SEAF 야포 포탄 6종과 확인된 운반 탄약·탄두는 15로 설정. 일반 주무기는 제외

백팩의 두 상호작용 구역은 모두 35로 설정합니다. 일반 폭발성 연료통과 일루미닛 캐니스터는 순정 거리로 두고, `primary_weapons` 경로의 일반 주무기 57종과 주무기일 가능성이 있는 미확인 무기 5종도 제외했습니다. Stalwart는 지원무기라 유지합니다. 재보급품의 별도 유닛은 Supplies 옵션에 포함됩니다.

v2.3은 `seaf_shell` 레코드만 15로 설정해 별도 레코드를 쓰는 SEAF 야포 포탄 변형 6종은 35로 남아 있었습니다. v2.4에서는 각 포탄 유닛의 경로를 확인하고 일반·고위력·미니 핵·네이팜·연막·정전기 포탄도 15로 설정했습니다.

이 숫자는 게임 내부 `ViewDistance` 값입니다. 화면의 미터 표시 기준으로 정확히 15m, 20m 또는 35m에 나타난다는 뜻은 아닙니다. 아이콘이 흐리게 나타나는 거리와 완전히 보이는 거리는 아이템마다 다를 수 있습니다. 줍기 거리는 그대로입니다. v2.4 SEAF 포탄의 최종 화면상 거리는 게임 안에서 확인이 필요합니다.

**v2.5 변경:** 게임 버전에 고정하지 않고 아이템을 ID로 찾아서, 작은 게임 업데이트 후에도 계속 작동합니다. 다른 모드나 업데이트로 달라진 아이템은 그것만 건너뛰고 나머지는 정상 적용합니다. 게임 시작 때의 순간 멈춤도 줄였습니다. 아이콘과 거리는 v2.4와 같습니다.

**설치:** HELLDIVERS 2(Steam build **25480438**에서 확인), [Bingus Shared Loader v15+](https://github.com/CowboyBingus/BingusSharedLoader)가 필요합니다. 이전 버전을 끄고 ZIP 하나를 Arsenal에 가져와 옵션을 선택한 뒤 **Purge → Deploy**하고 게임을 완전히 재시작하세요. ZIP 안에 자세한 설명이 있습니다.
