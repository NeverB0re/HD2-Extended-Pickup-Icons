# Extended Pickup Icons v2.4

게임에 원래 있던 플로팅 아이콘의 표시 거리만 조정합니다. 빛기둥과 발광 텍스처는 추가하지 않습니다.

지원 환경: **HELLDIVERS 2 Steam build 25480438**, **Bingus Shared Loader v15 이상**, Arsenal. 게임 EXE, game.dll 또는 로드된 데이터가 검증된 빌드와 다르면 메모리를 수정하지 않습니다.

## Arsenal 옵션

| 옵션 | 대상 | 설정하는 내부 ViewDistance |
| --- | --- | ---: |
| **Samples** | 일반·희귀·슈퍼샘플, 포장형 샘플, 정보 샘플 | **35.0** |
| **Supplies** | 탄약상자, 수류탄팩, 자극제, 재보급 포드의 보급품 | **20.0** |
| **Equipment & Mission Items** | 지원무기·보조무기·근접무기, 백팩, 샘플 운반체 및 대부분의 임무 운반물 | **35.0** |
| 같은 옵션의 운반 탄약·탄두 | SEAF 야포 포탄 6종과 기존 `seaf_shell` 레코드, SEAF 포 탄약, 사이보그 궤도포 탄약, 운반 탄두 | **15.0** |

세 옵션은 각각 켜고 끌 수 있습니다. 아무 옵션도 선택하지 않으면 데이터를 바꾸지 않습니다. Supplies를 켜면 자극제의 기존 핑 아이콘을 자동 표시하는 설정도 적용합니다.

**15.0, 20.0, 35.0은 게임 내부의 `ViewDistance` 값입니다.** 화면에서 아이콘이 흐리게 나타나는 지점과 완전히 보이는 지점은 아이템의 위치·크기·표시 규칙에 따라 다를 수 있어 정확히 15m, 20m 또는 35m라고 보증할 수 없습니다.

백팩의 두 구역은 모두 35.0, 보급품 구역은 모두 20.0으로 설정합니다. 슈퍼샘플을 포함한 샘플 구역도 35.0입니다. 일반 폭발성 연료통 `habs_barrel_fuel`과 일루미닛 캐니스터 `il_canister`는 패치 대상에서 제외해 순정 값 4.0으로 둡니다. 확인된 운반 탄약(`seaf_shell`, `seaf_gun_ammo`, `cy_orbital_cannon_ammo_carry`)과 탄두(`warhead_01`)는 15.0으로 설정합니다.

**v2.4 SEAF 수정:** v2.3은 `seaf_shell` 레코드만 15.0으로 바꾸고, 별도 레코드를 쓰는 포탄 변형 6종은 35.0으로 남겼습니다. 현행 데이터의 `UnitComponent`에서 이 변형들의 유닛 경로를 확인해 일반·고위력·미니 핵·네이팜·연막·정전기 포탄의 `ViewDistance`도 15.0으로 수정했습니다. 기존 `seaf_shell`의 15.0 설정은 유지합니다.

`primary_weapons` 경로의 일반 주무기 57종은 대상에서 제거했습니다. 이름이 확인되지 않은 단일 무기 5종도 주무기일 가능성이 있어 보수적으로 제외했습니다. **Stalwart는 지원무기이므로** 데이터 경로가 `primary_weapons/lmg_stalwart`여도 두 구역을 계속 35.0으로 설정합니다. 확인된 보조무기와 근접무기는 이번 요청에서 제외 대상으로 지정되지 않아 계속 35.0으로 설정합니다.

세 옵션을 모두 켜면 **251개 상호작용 구역**의 `ViewDistance`만 바뀝니다(Samples 30, Supplies 8, Equipment & Mission Items 213). 실제 줍기 거리(`Radius`), 상호작용 종류와 아이콘 그림은 바꾸지 않습니다.

이 모드는 시작 시 지원 빌드와 원본 데이터 전체를 확인하고, 한 번 적용한 뒤 실행 중 반복 검사를 멈춥니다. 같은 데이터를 먼저 바꾸는 다른 모드가 있으면 검증에 실패해 적용을 중단할 수 있습니다. 다른 모드와 함께 사용할 때 게임 내 성능과 화면 표시의 검증은 별도로 필요합니다.

## 설치 및 확인

1. 게임을 완전히 종료합니다. 창이 사라져도 작업 관리자에 `helldivers2.exe`가 남아 있다면 먼저 종료합니다.
2. 이전 Extended Pickup Icons 시험판과 v2.3을 비활성화하거나 교체합니다.
3. Bingus Shared Loader v15 이상을 활성화하고 이 ZIP을 Arsenal에 가져옵니다.
4. 원하는 옵션을 선택한 뒤 **Purge → Deploy**하고 게임을 새로 시작합니다.

`%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\CodexPickupIconRangeTest.log`에서 `extended-pickup-icons-2.4`와 적용된 구역 수를 확인할 수 있습니다. 세 옵션을 모두 켜면 `samples=30 supplies=8 equipment=213`이 기록됩니다.

v2.3의 실제 적용과 일반 연료통의 순정 거리 복귀는 확인했습니다. v2.4는 현행 데이터에서 여섯 포탄 변형의 유닛 경로를 대조하고 ZIP 구조, Shared Loader 탐색, 모든 옵션 조합과 보호된 메모리의 합성 시험을 통과했습니다. **v2.4의 SEAF 포탄 화면상 표시 거리는 게임 안에서 확인이 필요합니다.**
